# fin05

A browser game for a parent and their son to build together and learn from.

## Ground rules
- Plain HTML, CSS and JavaScript modules. No build step, no packages, no libraries. Deploys as a static site.
- Keep the code simple and well commented so a teenager can read and change it. Tuning numbers go at the top of each file.
- Build in small steps and test in the browser after each change. `node serve.mjs` serves it at http://localhost:5176.
- GitHub: `megarobogod/fin05`. Not connected to Vercel yet. Commits are made as `megarobogod` with the GitHub no-reply email.
